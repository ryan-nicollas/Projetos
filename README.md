# ✅ TaskFlow | Gerenciador de Tarefas

O TaskFlow é uma aplicação web para organizar e acompanhar tarefas do dia a dia, desenvolvida com HTML, CSS e JavaScript.

As tarefas ficam salvas no próprio navegador usando Local Storage. Assim, a lista continua disponível mesmo depois de fechar ou atualizar a página.

## 🚀 Funcionalidades

* ➕ Adicionar novas tarefas
* ✅ Marcar tarefas como concluídas
* 🗑️ Excluir tarefas
* 🔍 Filtrar por todas, pendentes ou concluídas
* 📊 Acompanhar a quantidade de tarefas pendentes
* 💾 Salvar as tarefas automaticamente no Local Storage
* ⌨️ Adicionar tarefas pressionando Enter
* 📱 Layout responsivo para diferentes tamanhos de tela
* 🌙 Interface em modo escuro
* ⚠️ Validação para evitar tarefas vazias

## 🛠️ Tecnologias utilizadas

* Local Storage
